# 19×19 乘法表乐园

面向小学生的移动端乘法表学习游戏。纯前端静态应用，Vue 3 + Vite + Vant 4，立体/3D 视觉风格，中文界面。

## 快速开始

```bash
cd multiplication-table-game
npm install
npm run dev
```

浏览器打开终端提示的本地地址（默认 `http://localhost:5173`）。手机可访问同一局域网 IP。

生产构建与预览：

```bash
npm run build
npm run preview
```

预览默认端口为 `4173`（`http://localhost:4173`）。

## 学习模式

| 模式 | 说明 |
|------|------|
| **九九表浏览** | 完整 1–19 乘法表网格，点格子看算式与答案；可筛选 1–9 / 1–12 / 1–19 |
| **闪卡练习** | 随机 `a×b=?`，点选或输入答案，即时对错与正确率；可设范围与计时 |
| **闯关挑战** | 10 关逐步扩大到 19，限时或限错；进度保存在 `localStorage` |
| **听声/遮罩记忆** | 先显示完整算式再遮住答案，或只显示积反推因数 |
| **连连看匹配** | 算式 ↔ 积配对消除（3D 翻转卡片） |
| **错题本复习** | 自动收集错题，做对移出；可清空 |

底部 Tabbar：首页 / 九九表 / 闪卡 / 闯关 / 更多。

## 体验说明

- 移动端优先，viewport 适配竖屏
- CSS 3D：卡片浮起阴影、按压缩放、翻转反馈
- 音效可选（右上角静音），使用 Web Audio 短音，无外链素材
- 无需后端，构建产物可任意静态托管

## 技术栈

- Vue 3 + Vue Router（Hash 模式，便于静态部署）
- Vite 8
- Vant 4（Tabbar、Field、Switch、Dialog、Toast 等）
- Sass + 手写立体样式
